# Morgan Kegode Major Medical Supplies

Website for a non-pharmaceutical medical supplies business based in Kakamega Town, Western Kenya.

## Files
- `index.html` - website structure and content
- `style.css` - responsive styling
- `script.js` - mobile navigation and current year

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `morgan-kegode-medical-supplies`.
2. Upload all three website files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the website address after deployment.

The WhatsApp button uses the Kenyan international format for 0116475174: `254116475174`.
